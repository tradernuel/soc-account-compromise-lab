# SOC Account Compromise Investigation Lab

## Overview

A hands-on cybersecurity lab focused on detecting and investigating
a simulated account compromise.

## Objectives

- Monitor Windows security events
- Detect suspicious authentication activity
- Investigate failed and successful logins
- Identify indicators of compromise
- Perform basic incident response
- Document findings professionally

## Lab Environment

- Windows Server
- Wazuh
- VirtualBox

## Investigation Scenario

A simulated user account will experience suspicious authentication
activity. The objective is to determine whether the account has
been compromised and document the investigation.

## Investigation Process

1. Detection
2. Investigation
3. Evidence Collection
4. Containment
5. Eradication
6. Recovery
7. Documentation
